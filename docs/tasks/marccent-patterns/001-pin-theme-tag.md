# Task 001: pin marccent-theme by tag, not by commit

Status: open
Repo: marccent-patterns
Issue: none
Branch base: the repo's default branch
Give to: Code in marccent-patterns

## Goal

Move the marccent-theme pin in `package.json` from a commit to a release tag, so patterns install a version, not a commit (`docs/RELEASES.md`).

## Files

- `package.json` (the `marccent-theme` dependency).
- `package-lock.json` (regenerated by npm).

## Exact steps

1. In marccent-theme, find the latest tag: `git ls-remote --tags https://github.com/marcoscenteno89/marccent-theme | tail -3`. Write down the newest `vX.Y.Z` tag. (At the time this task was written, it was `v1.0.0-rc.25`.)
2. In this repo, edit `package.json`: the `marccent-theme` dependency becomes `github:marcoscenteno89/marccent-theme#<that tag>`.
3. `npm install`, to update `package-lock.json`.
4. Run this repo's checks (below).
5. Commit on a new branch, push it, open a PR. The PR says which tag and why (the pin moves from a commit to a tag).

## Checks

- `npm test`. Paste the output. Expected: exit 0.
- `npm run build`, if the repo has it. Paste the output.

## Done when

- The pin is a tag, `npm test` exits 0, and the PR is open with the output in its body.
- Give Hub: the branch, the PR link, the tag used, and the output above. Hub verifies and merges.

## Notes

- If `npm test` fails after the pin moves, stop and report the output. Do not change the pin back without saying why.
